# HiStory
中国史世界史对照

## 版本管理规则
- **每次更新必须改版本号！**
- 版本号位置：`index.html` 中的 `<div class="version-tag">vX.X</div>`
- 当前版本：v2.4
- 版本号规则：小改动 +0.1，大功能 +1.0

## 项目约定
- 数据统一存储在 `timeline.sqlite` 中，不在 JS 中保留冗余数据副本
- 修改历史事件/朝代请直接编辑数据库文件
- minYear=-4000、maxYear=2026 固定不变
- 同类型事件间距不小于 210px（防碰撞）
- 详情页在新标签页打开，不离开时间轴页面
